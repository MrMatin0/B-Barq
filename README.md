# بی‌برق ⚡
> [!NOTE]
> [English README](README.en.md)

بی‌برق یک اپلیکیشن اندروید است که برنامه قطعی برق چند مکان را از منبع رسمی برق‌من مانیتور می‌کند و قبل از هر قطعی به شما یادآوری می‌فرستد.

## نحوه کارکرد
1. **با شماره تلفن همراه خود وارد شوید** (تایید با کد پیامکی از طریق برق‌من).
2. **یک یا چند مکان اضافه کنید**، هر کدام با شناسه قبض مخصوص خودش.
3. **دسترسی‌های لازم را بدهید.**
4. **سرویس فورگراند را استارت کنید** تا مانیتورینگ شروع شود.

سرویس هر ساعت منبع قطعی برق را چک می‌کند، آخرین برنامه‌ی همه‌ی مکان‌های شما را در یک نوتیفیکیشن ثابت نمایش می‌دهد، و بر اساس فاصله‌ی زمانی‌ای که برای هر مکان تنظیم کرده‌اید یادآوری می‌فرستد.

## امکانات
* مانیتور کردن **چند مکان** همزمان، هر کدام با برنامه قطعی مستقل.
* چک کردن ساعتی برنامه‌های رسمی قطعی برق.
* نوتیفیکیشن ثابت و قابل گسترش که قطعی‌ها را بر اساس فوریت مرتب می‌کند و مکان‌های ناموفق را جدا نشان می‌دهد.
* **فاصله زمانی یادآوری قابل تنظیم** برای هر مکان (مثلاً ۱۵ دقیقه، ۳۰ دقیقه، یا ۱ ساعت قبل)
* رابط کاربری متریال دیزاین ۳، ساخته‌شده با جت‌پک کامپوز.

## پیش‌نیازها
* اندروید 7 به بالا
* دسترسی به اینترنت
* یک شماره تلفن همراه معتبر برای ورود

## نصب
۱. آخرین نسخه APK را از [Releases](https://github.com/hesCalledAJ/B-Barq/releases) بارگیری کنید.
۲. فایل `SHA256SUMS.txt` همان انتشار را هم بارگیری کنید و سالم بودن فایل را بررسی کنید:

```bash
sha256sum -c SHA256SUMS.txt
```

۳. APK را روی دستگاه خود نصب کنید.
۴. وارد شوید، مکان‌های خود را اضافه کنید، دسترسی‌ها را بدهید و سرویس را استارت کنید.

> [!IMPORTANT]
> همه‌ی نسخه‌هایی که تا پیش از این منتشر شده بودند، به اشتباه با کلید دیباگ امضا شده بودند. از این پس انتشارها با کلید اصلی امضا می‌شوند و اندروید اجازه نمی‌دهد برنامه‌ای که کلید امضایش عوض شده به‌روزرسانی شود. اگر یکی از نسخه‌های قبلی را نصب کرده‌اید، **باید ابتدا برنامه را حذف و بعد نسخه‌ی جدید را نصب کنید** (اطلاعات ذخیره‌شده‌ی برنامه با حذف آن از بین می‌رود).

## ساخت از سورس

```bash
git clone https://github.com/MrMatin0/B-Barq.git
cd B-Barq
./gradlew assembleDebug
```

نیاز به JDK 17 و اندروید SDK 36 دارید؛ اگر JDK 17 نصب نباشد، خود Gradle آن را دریافت می‌کند. راهنمای کامل ساخت، ساختن کلید امضا و مراحل انتشار در [docs/BUILDING.md](docs/BUILDING.md) آمده است.

## حریم خصوصی
بی‌برق شماره تلفن همراه شما را فقط برای احراز هویت، و شناسه قبض‌ها را فقط برای دریافت برنامه قطعی برق استفاده می‌کند. **هیچ اطلاعات شخصی‌ای جمع‌آوری یا به اشتراک گذاشته نمی‌شود.**

اطلاعات ذخیره‌شده توسط برنامه روی خود دستگاه شما نگهداری می‌شوند. درخواست‌های مربوط به اطلاعات خاموشی برق نیز مستقیماً از برنامه به سرویس مربوطه ارسال می‌شوند.

هیچ SDK آنالیتیکس یا ردیابی در برنامه وجود ندارد. (در نسخه‌های قدیمی از Yandex AppMetrica استفاده می‌شد؛ این وابستگی حذف شده است.)

## مشارکت
از مشارکت شما استقبال می‌شود! اگر ایده، بهبود، یا رفع باگی دارید:
* مخزن را فورک کنید
* یک شاخه جدید بسازید
* یک پول ریکوئست بفرستید

پیش از فرستادن پول ریکوئست، `./gradlew assembleDebug test lint` را اجرا کنید؛ همین‌ها روی هر پول ریکوئست در CI هم اجرا می‌شوند.

* پشتیبانی از ویجت برای نمایش سریع وضعیت قطعی برق
